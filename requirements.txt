=====================================
EXAM: AWK, GREP, SED COMMANDS
=====================================

========== SECTION 1: AWK COMMANDS ==========

1. Print entire file:
awk '{print}' student.txt

2. Display without header:
awk 'NR>1 {print}' student.txt

3. Display lines 2 to 4:
awk 'NR>=2 && NR<=4 {print}' student.txt

4. Display fields 2 and 3:
awk '{print $2, $3}' student.txt

5. Average of MARK1:
awk 'NR>1 {sum += $3; count++} END {print sum/count}' student.txt

6. Count non-empty lines:
awk 'NF > 0 {count++} END {print count}' student.txt

7. Display as NAME | MARK1:
awk 'NR>1 {print $1 " | " $3}' student.txt

8. File content in lowercase:
awk '{print tolower($0)}' student.txt

9. Name starting letter uppercase:
awk '{print toupper(substr($1,1,1)) tolower(substr($1,2))}' student.txt

========== SECTION 2: AWK OPERATORS ==========

1. Record where name = SANJAY:
awk '$1 == "SANJAY"' student.txt

2. Records where MARK1 > 90:
awk '$3 > 90' student.txt

3. 2nd & 3rd line, 12th & 13th line:
awk 'NR%10 == 2 || NR%10 == 3' student.txt

4. Count number of fields:
awk '{print NF}' student.txt

5. Records where marks > 90:
awk '$3 > 90' student.txt

========== SECTION 3: GREP COMMANDS ==========

1. Count occurrences:
grep -c "rabbit" contents.txt

2. Display line numbers:
grep -n "rabbit" contents.txt

3. Case insensitive count:
grep -i -c "rabbit" contents.txt

4. Search in multiple files:
grep "rabbit" file1.txt file2.txt

5. Search multiple keywords:
grep -E "rabbit|hungry" contents.txt

6. Exact word:
grep -w "tortise" contents.txt

7. Lines NOT matching:
grep -v "rabbit" contents.txt

8. Search all subdirectories:
grep -r "rabbit" .

========== SECTION 4: SED COMMANDS ==========

1. Replace 'network' with 'os':
sed 's/network/os/g' sedtest.txt

2. Delete 2nd line:
sed '2d' sedtest.txt

3. Delete last line:
sed '$d' sedtest.txt

4. Delete lines with pattern:
sed '/subject/d' sedtest.txt

5. Insert blank line after every line:
sed 'G' sedtest.txt

6. Number each line:
sed '=' sedtest.txt | sed 'N; s/\n/ /'

7. Print last line:
sed -n '$p' sedtest.txt
